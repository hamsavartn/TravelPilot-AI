## Problem Statements
Participants must build their project according to one of the following Problem Statements:

### 1. EduPath: Personalized Learning & Skill Gap Agent
Build an AI-powered learning and skill-gap agent that creates personalized learning journeys. It should analyze learner profiles/resumes, identify skill gaps, recommend resources, generate weekly plans, and track progress dynamically.

### 2. FinPilot: Personal Finance Decision Support Agent
Build an AI-powered personal finance decision-support agent. It should categorize transactions from statements/bills, identify subscriptions, detect spending patterns, compare against budgets, and answer natural-language questions about financial data.

### 3. HireFlow: AI Candidate Screening & Interview Intelligence Agent
Build an AI-powered recruitment intelligence agent to help hiring teams organize and evaluate candidate information. It should extract skills from resumes, map to job requirements, generate interview questions, summarize notes, and maintain an audit trail.

### 4. ContractLens: Business Contract Review & Obligation Tracking Agent
Build an AI-powered contract intelligence agent that helps teams understand and track business agreements. It should extract key information (parties, dates, terms, obligations), track deadlines, compare versions, and summarize contracts.

### 5. TravelPilot: Intelligent Trip Planning & Disruption Management Agent
Build an AI-powered travel planning and itinerary management agent. It should build day-by-day itineraries based on constraints, optimize travel, adapt to disruptions (like cancellations), and provide a trip dashboard and natural-language Q&A.
